# User manual

The public manual is available at `/cookbook/manual`, with seven chapters and a Markdown download at `/cookbook/manual/download`.

The content lives in `src/examples/(workspace)/cookbook/manual/_lib/chapters.ts`. Both the reader and download use that same content. Edit it there so examples and explanations stay aligned.

The chapters cover the template, dependency ownership, Result/Failure, building a feature, backend adapters, durable interactions, and the limits of testing evidence. Framework bindings are SolidStart-specific; portable models retain the shared Flover contracts.
