# Superseded binding contracts

These are preserved source records, not passing tests or a blind oracle. The original Solid scaffold used a router-aware NavLink, item-array Breadcrumb, compound Tooltip, configurable Mark, and different control/layout names. The requested Next parity port replaces those APIs with explicit active state, composable breadcrumbs, callback slots and the shared template contracts. These old API suites cannot compile against the new contracts. Active Solid component tests and inherited browser suites cover representative composition, form, keyboard and accessibility behavior. They do not establish that every clause of these archived API suites has been revalidated. The copied Next action test is similarly replaced by real Solid server-action/browser checks.

Existing `custody/`, `decisions/` and `protocols/` records remain unchanged.
